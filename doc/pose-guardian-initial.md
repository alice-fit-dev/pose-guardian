작성일: 2026년 05월 01일

**1. 프로젝트 개요**

웹캠(모바일 포함)을 이용한 실시간 웨이트 트레이닝 자세 진단 기능을 기존
운동·식단 관리 웹앱에 추가하는 프로젝트입니다.

스쿼트, 데드리프트, 벤치프레스 등 여러 운동의 관절 각도를 실시간으로
분석하고 피드백을 제공하는 것을 목표로 합니다.

**현재 상황**

- 기존 앱: Python + Streamlit 기반 운동·식단 관리 웹앱 (Streamlit Cloud
  배포 완료)

- AI 연동: Claude, Gemini, OpenRouter, NVIDIA 등 멀티 프로바이더 선택
  구조

- 개발 환경: VS Code + Claude Code Extension

- 예산: 무료 인프라 최대 활용

**6. 기존 Streamlit 앱 성능 진단**

**6-1. 고칠 수 있는 것 (단기 개선)**

- genai.list_models() 매 렌더링마다 API 호출 (app.py:55) →
  \@st.cache_data(ttl=3600) 래퍼 추가

- menu_meal.py st.rerun() 남발 40회 → session_state 변경만으로 처리
  (주간 네비, 즐겨찾기/잠금/숨기기 토글, 삭제 확인 등)

- db.load_user_profile() 중복 호출 (chat.py, menu_1.py, dashboard.py) →
  캐시 적용으로 통합

**6-2. 구조적 한계 (Streamlit 자체 문제)**

- 데이터 동기화 후 전체 재실행: st.cache_data.clear() → 전체 무효화 →
  rerun 필연적 (선택적 캐시 무효화 미지원)

- 탭 컨텐츠 전부 렌더링: 비활성 탭이어도 build_sbd_summary() 등 분석
  함수 실행됨

- 인증/AI엔진 전환 rerun: 필요한 rerun으로 제거 불가

**6-3. Streamlit 느린 근본 원인**

> 클릭 한 번\
> ↓\
> 브라우저 → Python 서버로 전송\
> ↓\
> Python 서버에서 전체 스크립트 재실행 ← 핵심 문제\
> ↓\
> 결과를 브라우저로 다시 전송\
> ↓\
> 화면 갱신\
> \
> 기능이 많아질수록 재실행할 코드 증가 → 무조건 느려짐

  연구 완성 (Smart Brace for Knee Laxity Measurement, PMC 2022)

- 허벅지/정강이 IMU로 측정한 무릎 각도가 광학 모션캡처와 강한
  상관관계(R≥0.9), 스쿼트 기준 오차 4\~6도 (PubMed 2025)

- IMUPoser: 스마트워치 + 스마트폰 IMU 조합으로 피트니스·재활·자세교정
  적용 가능성 검증 (CHI 2023)
